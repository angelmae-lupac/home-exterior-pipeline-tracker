# Home Exterior Pipeline Tracker

A React + Vite job pipeline tracker for home-exterior contractors.

## Run locally

1. Install Node.js.
2. Open a terminal in this folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL Vite gives you, usually `http://localhost:5173/`.

## Production build

```bash
npm run build
npm run preview
```

The app includes Board, List, and Dashboard views, job creation/editing, estimates, search/filtering, responsive layouts for phones and small screens, and a light/dark theme toggle (remembers your choice and follows your OS setting by default).
